## What you can explore

- Browse terminology and learning resources.
- Take a replayable knowledge quiz.
- Explore the team and contact pages.

## Using the project

1. Browse the Learn page for terminology and historical context.
2. Try the Quiz and read the result.
3. Return to the learning resources and try another quiz attempt.

## Getting started

Requires a browser and a local HTTP server. Python 3 provides one without installing application packages.

```bash
git clone https://github.com/SamOBrienOlinger/24-7-hackathon-team9.git
cd 24-7-hackathon-team9
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [localhost:8000](http://localhost:8000). Serve the repository over HTTP so module imports, relative assets and page links resolve correctly.
